# Run Taka Sats for your community

Start with the maintained [fork-to-production guide](FORK_TO_PRODUCTION.md), also rendered in the
website's Docs section. It covers published source, independent infrastructure, secrets/settings,
demonstration versus real funds, staff/passkeys, external funding, production checks, backups and upgrades.

No Afribit account or permission is required for an AGPL-compliant deployment. You still need a
capable operator, independent credentials and funding. Read [open source and independence](OPEN_SOURCE.md).

The previous procedure was replaced because it omitted phone setup/configuration precedence and
contained stale universal-approval/demo-default assumptions. For engineering setup see
[development](DEVELOPMENT.md); for operations see [field integrity](FIELD_INTEGRITY.md).
